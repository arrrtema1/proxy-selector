# Proxy selector

PowerShell скрипт для проверки и выбора прокси-серверов по странам с параллельным тестированием.

## Возможности

- 🌍 **Выбор по странам** — все прокси сгруппированы по странам, отсортированы по алфавиту
- 🌐 **Worldwide** — специальная категория для прокси с динамическими IP
- ⚡ **Параллельная проверка** — все прокси проверяются одновременно (до 20 потоков)
- 🚀 **Быстрый результат** — проверка всех прокси занимает ~3-4 секунды
- 📊 **Статистика** — показывает количество рабочих прокси
- 📁 **Внешний файл** — список прокси хранится отдельно от скрипта
- 💻 **Работает на любом Windows** — использует PowerShell 5.1 (есть в каждой Windows 10/11)

Для запуска откройте run.bat
